# Skill portátil: recriar animação por código

Este pacote contém instruções e exemplos reutilizáveis, não um gerador que copia automaticamente qualquer vídeo. A qualidade depende da análise da referência, coreografia manual e revisão das prévias.

## Outro chat no Codex

A skill está no repositório em `.agents/skills/recriar-animacao-por-codigo/SKILL.md`, na branch de entrega `video-2026-10-14-em-partes-e5fc9397`. Em um novo chat com esse repositório e essa branch, peça para ler e usar essa skill. Se a interface não a listar automaticamente, indique o caminho do arquivo. Isso ocorre no ambiente do projeto na nuvem.

Para outro repositório, copie a pasta `recriar-animacao-por-codigo` para `.agents/skills/` do projeto. Não é necessário instalar algo neste computador de trabalho para ler ou transferir os arquivos pelo navegador.

## ChatGPT comum ou outra aplicação

Anexar este ZIP não instala automaticamente uma skill. Se a aplicação aceitar e ler o anexo, peça: “Leia o SKILL.md deste pacote e siga o método para esta nova referência”. Também forneça a referência e, para reaproveitar a implementação inteira, o ZIP do código do projeto. A forma de importar skills varia por aplicação.

O arquivo principal segue o formato Markdown com frontmatter YAML. A compatibilidade de importação com ferramentas de terceiros deve ser conferida na aplicação correspondente.

## O que acompanha

- `SKILL.md`: método e regras de execução.
- `references/`: fluxo de trabalho e contrato dos modelos.
- `templates/`: rig, desenho e biblioteca Motion com licença, reaproveitados do projeto.

O código completo com as cinco coreografias está na pasta `videos/whatsapp-2026-10-14` da mesma branch. As prévias e a montagem são aproximações dirigidas, não equivalência perfeita de todos os frames.
