# Clone — reconstrução 3D dirigida

- `projetos/clone-video`: código, roteiro, áudio e relatórios de validação.
- `vídeos/clone-3d-completo.mp4`: somente o filme completo.

A reconstrução usa personagens articulados e cenários procedurais em Three.js, com a faixa de áudio original. É uma aproximação 3D da referência de 8min45s, seguindo o método escolhido, e não uma réplica visual exata. Instruções e limites estão em `projetos/clone-video/README.md`.
