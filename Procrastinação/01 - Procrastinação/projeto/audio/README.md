# Narração original

Para renderizar novamente, coloque o arquivo `teste1.wav` fornecido pelo usuário
nesta pasta com o nome `narracao.wav`. O WAV fica fora do Git e do ZIP.

Para assistir, o MP4 completo já contém a narração e o player usa esse MP4.
O botão “Carregar narração” também permite selecionar o áudio no navegador,
sem enviar o arquivo a um serviço de transcrição.
