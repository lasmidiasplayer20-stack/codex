# Skill reference-animation

Este pacote contém `SKILL.md`, o fluxo técnico e uma base de código para recriar
animações 2D por articulações, refinar movimentos rápidos e exportar MP4.

Para um novo chat, anexe `SKILL.md` (ou o pacote, se a interface aceitar ZIP) e o
novo vídeo. Use uma instrução explícita:

> Leia a skill reference-animation e use seu fluxo para recriar o vídeo anexado
> em código, com movimentos fluidos e personagens mais grossos e curvos.

Anexar o arquivo leva as instruções para a conversa; não registra automaticamente
uma skill nem habilita ferramentas. Em uma instalação Codex com suporte a skills
locais de projeto, a pasta pode ser colocada em
`.agents/skills/reference-animation/` no repositório e aberta em uma nova sessão.
A instalação por interface depende dos recursos que ela disponibiliza.

A base é um exemplo testado, que precisa ser adaptado à nova referência. Não há
vídeo original, trilha, dados de movimentos da entrega, credenciais ou sessões de
upload neste pacote. Os requisitos e a licença do Motion estão em `template/`.
Os scripts devem rodar na máquina de execução apropriada, não precisam ser
instalados no computador de trabalho para assistir aos resultados.
