# O botão de desfazer — One More Take

**3min30s · 1920×1080 · 60 fps · cores · áudio estéreo.**

[Abrir o filme completo](O-bot%C3%A3o-de-desfazer-1080p60.mp4). No GitHub, use **Download raw file / Baixar arquivo bruto** para baixar o MP4.

Uma tentativa de entregar um bolo vira uma sucessão de acidentes. Amber encontra um botão que desfaz cinco segundos — mas o controle tem apenas cinco cargas.

O curta foi produzido em sete partes de 30s, com atuação e roteiro novos. A música é original por síntese; os 24 efeitos foram gerados com ElevenLabs e usados em 153 eventos de ação e passos. As partes numeradas são os blocos de produção; o filme completo reúne todas com uma trilha contínua.

[Código editável, roteiro e reprodução](../../projetos/botao-desfazer/README.md) · [Relatórios de validação](../../projetos/botao-desfazer/qa/).

Os personagens preservam o perfil e o desenho-base da entrega anterior. As animações anteriores em `exports/` continuam preservadas.
