# Shared animation kit

This is a source and asset library, not a third active skill. Read the sibling `animation-from-reference/SKILL.md` or `original-stick-animation/SKILL.md` for the chosen workflow.

The kit retains the preserved rig, physics, original/reference production examples, 28 reusable ElevenLabs effects and six Animation vs Physics snapshots. Historical instructions are reference documents. The latest reference example includes a floor-projection adapter, an explicit three-person elevator cast, measured facial features, original Python music and validation reports.

Full source history is available in the complete ZIP and browsable GitHub folder. Portable ZIPs retain all source code, reusable effects, current reference audio and selected visual reviews; repeated historical mixed soundtracks and large archival contact sheets are omitted from those smaller downloads.
