# Arckkiller animation skill

Download **[stick-physics-animation.zip](stick-physics-animation.zip)** and extract it. The entry point is **[SKILL.md](stick-physics-animation/SKILL.md)**. The unpacked directory is also browsable here.

Includes the original rig and drawing code, physics and contact implementations, all six Animation vs Physics reference versions, the three Arckkiller project source trees, visual review images, reusable ElevenLabs effects, story/production documentation and practical project initialization and reference extraction scripts. Full movies remain at their existing GitHub locations, listed with verified hashes in the video catalog; dependencies and temporary renders are excluded.

## Use in a new request

Attach the ZIP or make the extracted directory available to the agent. Ask it to read `stick-physics-animation/SKILL.md` and follow the workflow. In tools that support local skills, install that directory in the tool's skill directory (for Codex, typically `$CODEX_HOME/skills/stick-physics-animation`), then start a new session so it can discover the skill. A repository folder by itself does not automatically activate a skill.

Example requests:

> Use $stick-physics-animation to create an original 3:30 colorful stick-character film in a clockwork greenhouse. Use native-time continuous action, concurrent tasks, the preserved rig and polished contacts. English visible text. Complete MP4s go in Arckkiller/Animação/Vídeos.

> Use $stick-physics-animation with the attached reference video. Analyze its silhouettes, weight, contacts, color, camera and timing, then create a new scenario with the same movement language. Work internally in parts and review nearby frames at every difficult contact.

For a web chat without installed skill discovery, replace `$stick-physics-animation` with “Read and follow the attached SKILL.md”. Attach visual references separately when they are not already bundled.

## Contents

- `stick-physics-animation/SKILL.md`: instructions for future animation requests.
- `stick-physics-animation/project-archive/`: reusable project code, audio, tests and historical QA.
- `stick-physics-animation/references/`: original documentation, six version snapshots, visual references and production guides.
- `stick-physics-animation/scripts/`: initialize a portable working project, extract references, fetch full films and verify integrity.
- `stick-physics-animation/PROVENANCE.json` and `MANIFEST.json`: origin and file integrity.
- `stick-physics-animation.zip`: the complete source/asset skill package, with the same files as the unpacked directory.
- `PACKAGE-REPORT.json` and `stick-physics-animation.zip.sha256`: packaging and validation evidence.

Use project material only within the permissions attached to it; packaging does not grant a new license for third-party assets or generated audio. No API credentials are included.
