# Pacotes para YouTube

Cada vídeo tem uma subpasta própria, com a capa e os textos prontos para copiar.

- [Andar ou correr na chuva?](andar-ou-correr-na-chuva/README.md)

## Estrutura de cada vídeo

```text
nome-do-video/
  capa.jpg              # imagem de upload, 16:9, abaixo de 2 MB
  capa-original.png     # original de alta resolução
  titulo.txt            # título escolhido
  descricao.txt         # descrição e capítulos
  tags.txt              # tags em uma linha, separadas por vírgula
  metadados.json        # mesmos dados em formato estruturado
  README.md             # prévia e orientação editorial
```

Use uma pergunta visual clara na capa e um título complementar. Descrição e capítulos devem corresponder ao conteúdo do filme; não invente dados, promessas ou resultados. Ajuste os tempos ao revisar o vídeo. A criação destes arquivos não publica o conteúdo no YouTube.
